# Migration from v1.5.2 to v1.6

Version 1.6 is a breaking methodology change. Do not compare a v1.6 fair value directly with a v1.5.2 fair value without rebuilding the valuation.

## What changed

| v1.5.2 behavior | v1.6 treatment | Reason |
|---|---|---|
| Fair P/E selected from sPEG bands | Headline sPEG is diagnostic; fair value comes from explicit cash-flow scenarios | Ordinal factor scores are not calibrated price multipliers |
| Fixed rate and cycle haircuts | Scenario-specific EPS, conversion, terminal growth, and required return | Fixed multipliers obscured timing and could double-count risk |
| F4 could turn a cycle haircut on/off | F4 is evidence; reversion changes named operating assumptions | Prevents weaker F4 from mechanically raising value |
| Mid-cycle EPS could be called Forward P/E | NTM EPS is mandatory for headline Forward P/E; normalized P/E is separate | Restores definition consistency |
| Effective SM and rent caps | Structural SM remains visible; rent leakage lowers F4 or scenario economics | Removes an undefined score-to-value mapping |
| Separate windfall credit | Explicit cyclical EPS/cash path | Avoids double counting forecast cash flows |
| Excess-cash add-on without an earnings bridge | Cash can be added only after related net interest is removed from EPS | Avoids counting cash in both earnings and balance-sheet value |
| Valuation tiers used action language, and crowding could cap them | Tiers describe price/value distance only; crowding affects portfolio action and margin of safety | Separates intrinsic value from positioning and action |
| Constructed estimates could be described as consensus | Missing consensus stays missing; analyst paths are labeled assumptions | Enforces source discipline |
| Price-independent actions | Every action requires price, thesis, and portfolio conditions | Prevents unconditional recommendations |

## Reusing old work

You may reuse evidence and factor scores only after confirming that all five scores referred to the same scarce asset and that the evidence is current. Recompute Forward P/E, CAGR, sPEG, and every scenario value with the v1.6 calculator.

Do not preserve a legacy target merely to minimize the numerical change. Methodology consistency takes priority.

## Canonical arithmetic correction

The legacy worked example used `33 x 0.85 x 0.75 x 0.85` and reported approximately `16.2x`. The product is approximately `17.88x`. Version 1.6 retires that multiplier chain entirely, so correcting the multiplication is necessary but not sufficient; the fair value must be rebuilt from cash-flow scenarios.
